# AVL_tree

## Description
삽입과 삭제 명령어로 확인 가능한 AVL 트리 구현

## 사용 방식
다음을 입력하여 main.cpp를 컴파일 후에 실행시킨다.

    g++ -g main.cpp

## 커맨드 예시
i <key>
d <key>
t <key>

## 커맨드 설명
- i <key> : 트리에 value가 key인 노드를 삽입한다.
- d <key> : 트리에 value가 key인 노드를 삭제한다.
- t <key> : 트리에서 value가 key인 노드의 bf(Balance Factor), height를 확인한다.
